## 3. 路线A：文献计量学论文——特征体系升级

### 3.1 现有特征体系的局限性

当前六个特征（ASL/MWL/LD/LC/JD/HD）均为**浅层计数统计量**，在方法论上存在以下不足：

| 问题 | 具体表现 | 在论文评审中的风险 |
|------|----------|-------------------|
| TTR 长度偏倚 | LC 随摘要增长系统性下降 | 语言学常识，评阅人必然指出 |
| 分句不准确 | `.count('.')` 将缩略语中的句点计为句号 | 方法论粗糙 |
| 术语匹配粗糙 | `term in text` 子串匹配，无词边界 | 方法论过时 |
| 维度单一 | 全部在词/句层面，无句法、篇章、语用维度 | 论文缺乏理论高度 |
| 理论支撑弱 | 特征选择基于"方便计算"而非语言学理论 | 难以通过方法论审稿 |

### 3.2 升级方案：四层次特征体系

```
                    当前覆盖              建议新增
                  ┌──────────┐    ┌──────────────────┐
词级 (Lexical)     │ MWL      │    │ MTLD, MATTR      │ 词汇多样性
                  │ LD       │    │ 形容词/名词比例    │ 语法复杂度
                  │          │    │ 型例比替代指标     │
                  ├──────────┤    ├──────────────────┤
句级 (Syntactic)   │ ASL      │    │ 句法树深度        │ 句法复杂度
                  │          │    │ 从句密度          │ 嵌入层级
                  ├──────────┤    ├──────────────────┤
篇章级 (Discourse) │   —      │    │ Flesch Reading Ease│ 可读性
                  │          │    │ 衔接词密度        │ 衔接手段
                  │          │    │ 修辞结构比例      │ 篇章策略(Swales IMRD)
                  ├──────────┤    ├──────────────────┤
语用级 (Pragmatic) │ JD       │    │ TF-IDF 加权术语   │ 术语-可替代
                  │ HD       │    │ 模糊/确定比       │ 言据性
                  │          │    │ 情态动词分布      │ 语气策略
                  └──────────┘    └──────────────────┘
```

### 3.3 各特征详解

#### 词级特征

| 特征 | 缩写 | 计算方式 | 语言学基础 | 实现库 |
|------|------|----------|-----------|--------|
| 平均词长 | MWL | 去标点字符数/总词数（保留） | 词汇复杂度 | — |
| 词汇密度 | LD | (总词数−停用词)/总词数（保留，修复） | 词汇信息量 | — |
| **词汇多样性(MTLD)** | MTLD | Measure of Textual Lexical Diversity — 测量文本达到特定TTR阈值所需的平均词数，**不随文本长度偏倚** | McCarthy & Jarvis (2010) | `lexicalrichness` |
| **词汇多样性(MATTR)** | MATTR | Moving Average Type-Token Ratio — 滑动窗口TTR的均值 | Covington & McFall (2010) | `lexicalrichness` |
| **语法复杂度** | GC | 形容词+副词数 / 总词数 | Biber (1988) 多维度分析 | `spaCy` POS tagging |

#### 句级特征

| 特征 | 缩写 | 计算方式 | 语言学基础 | 实现库 |
|------|------|----------|-----------|--------|
| 平均句长 | ASL | 总词数/句子数（保留，改用spaCy分句） | 句法复杂度 | `spaCy` sentencizer |
| **句法树深度** | STD | 依存树的最大/平均深度 | 依存语法 (Tesnière, 1959) | `spaCy` dependency parse |
| **从句密度** | CD | 从句数(acl+advcl+ccomp+xcomp+csubj) / 句子数 | 句法嵌入层级 | `spaCy` dependency labels |

#### 篇章级特征

| 特征 | 缩写 | 计算方式 | 语言学基础 | 实现库 |
|------|------|----------|-----------|--------|
| **可读性指数** | FRE | Flesch Reading Ease = 206.835 − 1.015×(词/句) − 84.6×(音节/词) | Flesch (1948) 信息论可读性 | `textstat` |
| **衔接词密度** | COD | 逻辑连接词数(however/therefore/moreover等) / 句子数 | Halliday & Hasan (1976) 衔接理论 | 自定义词表 |
| **修辞结构比例** | RSR | 将摘要按 IMRD 分段，计算 Results/Discussion 段占比 | Swales (1990) 体裁分析 | 关键词正则匹配 |

#### 语用级特征

| 特征 | 缩写 | 计算方式 | 语言学基础 | 实现库 |
|------|------|----------|-----------|--------|
| TF-IDF术语评分 | JDT | 术语词表的TF-IDF加权得分（替代简单子串计数） | 信息检索 | `sklearn` |
| **模糊/确定比** | HDC | (模糊限制语数 − 确定性表达数) / 总词数——正值=谨慎，负值=自信 | Hyland (2005) 元话语理论 | 扩展词表 |
| **情态分布** | MOD | 情态动词数(can/may/must/should/will/could等) / 句子数 | Palmer (2001) 情态系统 | `spaCy` POS |

### 3.4 分析方法的同步升级

| 当前方法 | 升级为 | 目的 |
|----------|--------|------|
| Pearson 相关 | 偏相关（控制 `source_journal`, `year`, `word_count`） | 消除混杂变量 |
| 单一决策树 | 随机森林 + 5折交叉验证 + **SHAP** 特征重要性 | 稳定性 + 可解释性 |
| 全部样本建一个模型 | 按期刊分组 + **元分析** (forest plot) | 检验跨期刊一致性 |
| — | **主成分分析 (PCA)** | 验证特征体系内在结构 |
| — | **层次聚类**（对特征而非样本） | 发现特征的学科分组 |

## 4. 路线B：摘要写作辅助系统——条件语言模型微调

### 4.1 系统目标

构建一个面向腐蚀科学领域的摘要写作 Copilot，具备两个核心功能：
- **实时风格评估**：在用户写作过程中，逐句计算升级版文体特征，与高被引论文的"黄金区间"比较
- **风格感知的续写建议**：根据用户指定的风格偏好（如"提高术语密度"、"降低模糊性"），生成符合要求的续写候选

### 4.2 技术路线

```
Phase 1: 数据准备（1周）
  5682篇摘要 → 清洗 → tokenizer → HuggingFace Dataset
  按 NCC 分档 → 高/低 NCC 组 → 风格标签

Phase 2: 基座模型微调（1.5周）
  GPT-2 Small (124M) → LoRA → 腐蚀领域因果语言模型
  评估: 困惑度、领域词覆盖率、生成多样性

Phase 3: 风格条件注入（1.5周）
  特殊 token: <|high_jd|> <|low_hd|> <|nc_high|> 等
  → 训练模型理解"风格指令 → 输出分布"的映射
  → 评估：风格条件 → 生成文本的特征值是否朝预期方向偏移

Phase 4: 系统集成（1周）
  Streamlit 前端 + 实时特征计算 + 模型推理
  雷达图可视化 + NCC 预测值展示
```

### 4.3 基座模型选择

| 候选 | 参数量 | Colab T4 可行性 | 理由 |
|------|--------|----------------|------|
| **GPT-2 Small** (首选) | 124M | 轻松 | 教程丰富，快速跑通全流程 |
| **SmolLM2-1.7B** (备选) | 1.7B | 可（QLoRA） | 效果远优于 GPT-2，作为最终模型 |

策略：先用 GPT-2 Small 跑通，再用 SmolLM2 做最终版本。

### 4.4 风格条件设计

从路线A的 12 个特征中选择 4-6 个最稳定、可解释性最强的，设计为可调节的风格维度：

| 风格维度 | 控制 token | 低值含义 | 高值含义 |
|----------|-----------|----------|----------|
| 术语密度 | `<jd_low>` `<jd_high>` | 通识性语言 | 高度专业化 |
| 语气确定度 | `<hd_low>` `<hd_high>` | 谨慎、多模糊 | 自信、少模糊 |
| 句法复杂度 | `<sc_low>` `<sc_high>` | 短句、简单结构 | 长句、多层嵌入 |
| 可读性 | `<re_low>` `<re_high>` | 高可读性 | 学术化表达 |

训练时将控制 token 拼接到输入前缀中，模型学会在生成时遵从风格指令。

### 4.5 比赛策略

AI 相关比赛的评审通常关注三个维度，本项目的定位：

| 维度 | 本项目的优势 | 差异化 |
|------|-------------|--------|
| **创新性** | 自建领域语料微调 + 风格量化控制，非标准化任务 | 绝大多数参赛者用公开数据集做分类 |
| **完整性** | 数据采集→特征工程→模型训练→产品化，全栈链路 | 大多数项目停留在模型训练一层 |
| **实用性** | 面向研究生写摘要的真实场景 | 有明确的目标用户和使用场景 |

## 5. 路线C：专利——技术方案锁定

### 5.1 可专利化的技术点

专利要求"技术方案"而非"科学发现"。以下是从路线A和路线B中可提取的专利点：

| 编号 | 技术点 | 来源 | 专利化表述 |
|------|--------|------|-----------|
| P1 | 多层次文体特征实时量化 | 路线A | 一种从词级、句级、篇章级、语用级四个层次对学术文本进行实时文体特征量化的方法 |
| P2 | 高被引风格区间生成 | 路线A | 一种基于历史文献数据库的高被引摘要文体特征理想区间的统计生成方法 |
| P3 | 风格条件语言模型 | 路线B | 一种将文体特征值编码为控制token并嵌入语言模型输入以控制输出风格的方法 |
| P4 | 领域术语引导排序 | 路线B | 一种结合领域TF-IDF术语权重与语言模型输出概率的候选词排序方法 |
| P5 | 逐句影响力预测 | 路线A | 一种基于机器学习模型的学术文本段落影响力预测方法 |

### 5.2 专利结构建议

```
发明名称：一种基于多层次文体量化的学术摘要辅助写作方法及系统

独立权利要求1（方法权利要求）：
  一种学术摘要辅助写作方法，其特征在于，包括：
  (a) 获取用户输入的部分摘要文本；
  (b) 对所述部分文本在词级、句级、篇章级、语用级四个层次上
      实时计算多个文体特征值；
  (c) 将所述特征值与预设的理想区间比较，生成风格偏离提示；
  (d) 接收用户选择的风格调整指令；
  (e) 将所述风格调整指令编码为控制token，
      与所述部分文本拼接后输入经过领域微调的语言模型；
  (f) 输出符合所述风格调整指令的候选续写文本。

独立权利要求N（系统权利要求）：
  （对应上述方法的系统装置描述）

从属权利要求（具体限定）：
  - 词级特征的计算方法
  - 理想区间的统计生成方式
  - 控制token的编码方式
  - 语言模型的微调方法
  - 术语表的构建与权重计算方法
```
