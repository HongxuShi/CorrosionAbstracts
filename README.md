# 腐蚀领域学术摘要文体特征与影响力关联分析

---

## 项目简介

摘要是科研成果传播过程中起到最重要作用的文本之一，其写作方式不仅影响论文内容的传递效率，也可能影响论文的传播效果与学术影响力。然而，目前关于摘要文体特征与学术影响力之间关系的研究仍相对有限，尤其缺乏基于数据科学方法的系统分析。

本项目以腐蚀科学领域论文摘要为研究对象，通过文本分析、统计分析与机器学习方法，探索摘要文体特征与论文引用数之间的关系。

本仓库最初来源于本科阶段的一项课程研究，目前已转变为长期维护的数据科学研究项目。未来将在数据规模、文本特征、分析方法及评价体系等方面持续扩展。

---

## 研究目标

本项目围绕以下几个核心问题展开：

- 学术摘要的文体特征是否能够进行量化描述及如何确保这种量化描述涵盖了文体的绝大多数特征？
- 文体特征是否与论文的学术影响力存在关联？
- 哪些文体特征对学术影响力具有较强的解释能力？
- 文体特征与学术影响力之间究竟呈现线性关系还是非线性关系？

在完成以上内容的探讨后，本项目拟建立一个摘要语言风格的分析程序，提供摘要写作中通过语言特征在一定程度上提高被引概率的建议。

---

## 当前研究进展

### 数据采集

目前已完成：

- 基于 OpenAlex 数据库自动采集论文数据
- 获取论文摘要及引用信息
- 构建规范化引用指标（Normalized Citation Count，NCC）

当前数据集包括：

- **期刊：** 腐蚀科学（Corrosion Science）
- **语言：** 英文
- **样本量：** 377 篇论文

---

### 文体特征构建

当前已构建六项基础文体特征：

| 特征 | 缩写 |
|------|------|
| 平均句长 | ASL |
| 平均词长 | MWL |
| 词汇密度 | LD |
| 词汇高级度 | LC |
| 术语密度 | JD |
| 层次结构密度 | HD |

这些特征构成当前项目的第一代人工设计文体指标。

当前分析流程如下：


- K-Means 聚类
- 决策树分类

---

## 当前研究发现

截至目前，项目得到以下初步结果：

- 文体特征与论文引用表现之间未表现出明显的线性关系；
- 决策树模型能够捕获一定程度的非线性规律；
- 术语密度（JD）是当前数据集中最重要的判别特征；
- 平均句长（ASL）几乎不参与模型决策；
- 当前数据集尚不足以支持更加复杂模型的稳定训练。

以上结论仅代表当前数据集下的初步发现，仍需进一步扩大数据规模并引入更多分析方法进行验证。
